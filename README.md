# Yuginong Light

VS Code용 **라이트 테마**입니다. 요소별 색상 구분을 확실하게 했습니다.

클로드랑 같이 만들었습니다.

## 설치

마켓플레이스에는 올리지 않고 GitHub Releases로만 배포합니다.

1. [Releases](https://github.com/Faavilla/yuginong-theme/releases/latest)에서 `yuginong-theme-<버전>.vsix`를 내려받습니다.
2. VS Code 확장 뷰(`Ctrl+Shift+X`, macOS는 `Cmd+Shift+X`) 오른쪽 위 `...` 메뉴에서 **Install from VSIX...**를 선택하고 내려받은 파일을 고릅니다.
3. 명령 팔레트(`Ctrl+Shift+P`, macOS는 `Cmd+Shift+P`)에서 **Preferences: Color Theme**을 열고 **Yuginong Light**를 선택합니다.

터미널에서 설치할 수도 있습니다.

```bash
code --install-extension yuginong-theme-<버전>.vsix
```

VS Code 1.140.0 이상이 필요합니다.

## 업데이트

마켓플레이스를 거치지 않아 자동 업데이트되지 않습니다. 새 버전의 `.vsix`를 같은 방법으로 설치하면 기존 버전을 덮어씁니다.
